# Historical References

This directory contains material retained for comparison only:

- `old_demo_params_reference.json`: the single legacy flat parameter snapshot.
- `logs/legacy_demo_success.log`: selected successful run from the retired runner.
- `logs/legacy_demo_failure.log`: selected failed run from the retired runner.

No production code or notebook reads these files. Current settings live in `config.json` and `empirical_parameters.json`.
